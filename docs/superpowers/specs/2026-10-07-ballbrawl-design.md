# BallBrawl — дизайн (v1)

Рабочее название. Веб-игра: шары со суперсилами дерутся в арене. Вдохновлено Roblox «Ball VS Ball», но шары, названия и графика — свои.
Цель — заработать на рекламе Google AdSense (H5 Games Ads) с блокировкой харам-категорий.

## Решения

| Вопрос | Решение |
|---|---|
| Платформа | Веб (браузер, телефон + компьютер). Без Apple/Google-сторов. |
| Аудитория | Все возрасты, казуальная. |
| Реклама | Свой сайт + AdSense H5 Games Ads (Ad Placement API). |
| Игра игрока | Целится и запускает, дальше бой идёт сам. Против компьютера, без сервера. |
| Матч | Отряд из 3 шаров, дуэли 1 на 1 по очереди. |
| Технологии | Чистый JS (ES-модули) + Canvas 2D. Без фреймворков, без сборки, без зависимостей. |

## Матч

- У каждой стороны отряд из 3 шаров, порядок выбирает игрок (компьютер — по уровню).
- **Раунд:** оба шара стоят на стартовых точках (игрок — снизу слева, враг — сверху справа). Игрок тянет пальцем/мышью от своего шара — появляется стрелка; отпустил — оба шара запускаются (угол врага выбирает ИИ).
- Шары летят с **постоянной скоростью**, отражаются от стен, при столкновении друг с другом отскакивают и наносят урон. Способности срабатывают сами.
- Раунд заканчивается, когда у одной стороны на поле не осталось живых объектов. Если обе стороны умерли в один тик — обе теряют шар.
- **Победитель остаётся** с текущим HP; в следующем раунде против него выходит следующий шар врага, оба снова стартуют со своих точек, игрок снова целится.
- **Внезапная смерть:** через 30 с раунда все объекты теряют HP, урон растёт каждую секунду (2, 3, 4… HP/с).
- Матч проигран, когда потеряны все 3 шара.

## Физика

- Логическая арена 400×400, масштабируется под экран (портрет на телефоне, по центру на компьютере).
- Фиксированный шаг 60 Гц (аккумулятор поверх `requestAnimationFrame`).
- Столкновение шар–шар: упругое, равные массы; после — скорость нормализуется обратно к постоянной. Перезарядка урона 0,3 с на пару.
- **Урон от напора:** каждый шар бьёт на `урон × (0,5 + напор)`, где напор 0…1 — насколько прямо он врезался (лоб в лоб ×1,5, вскользь ×0,5). Даёт смысл прицелу и случайность исходу.
- Отражение от стен: инверсия компоненты скорости + случайный поворот ±0,3 рад (без этого шары уходят на «орбиты» и не встречаются).
- **Самонаведение:** шар плавно доворачивает к ближайшему врагу (1,2 рад/с). Без него встреча раз в ~4 с и раунды упирались во внезапную смерть; с ним раунд ~10 с.
- Случайность только через сидированный ГПСЧ (mulberry32) — симуляция детерминирована и тестируема.

## Шары (6 на старте)

Базовые значения: радиус 30, скорость 300 ед/с, урон касания 12. Все числа — константы вверху `src/balls.js`, подобраны скриптом `npm run balance` (средний % побед каждого шара 39–54%).

| Шар | HP | Способность |
|---|---|---|
| Обычный | 120 | Нет. Стартовый, бесплатный. |
| Пиявка | 90 | При ударе по врагу (перезарядка 4 с) прилипает на 2 с: движется вместе с ним, высасывает 5 HP/с и лечит себя на столько же. |
| Клетка | 85 | Когда умирает (один раз) — распадается на 2 мини-клетки: радиус 20, HP 30, урон 6, скорость 320. |
| Поезд | 100 | Первый через 2 с, дальше каждые 4,5 с: рельсы там, где враг окажется (1 с предупреждение), затем поезд проносится за 0,6 с — враг в полосе получает 22 урона. Хозяина не бьёт. |
| Ниндзя | 90 | Бросает сюрикен во врага каждые `0,4 + 1,2 × (HP / maxHP)` с (первый через 0,8 с). Скорость 500, урон 6. |
| Паук | 105 | При ударе о стену оставляет паутину (радиус 65, 5 с, максимум 3). Враг в паутине: скорость ×0,4 и 7 HP/с. |

Модель шара: данные (HP, радиус, урон, цвет) + обработчики событий `onWallHit`, `onEnemyHit`, `onTick`, `onDeath`. Новые шары добавляются одной записью.

## ИИ

- Целится в текущую позицию шара игрока + случайная ошибка угла; ошибка уменьшается с уровнем лестницы.
- Отряд врага собирается из шаров, доступных на этом уровне.

## Прогресс

- **Лестница** из 30 уровней по формуле: уровень `n` → HP врага ×`(1 + 0,05·(n−1))`.
- **Монеты:** победа — `20 + 2n`, поражение — 5.
- **Магазин:** конкретный шар за известную цену (Пиявка 100, Клетка 150, Паук 150, Ниндзя 200, Поезд 250). Никаких случайных сундуков.
- **Сохранение:** `localStorage` — `{coins, owned[], level}`.
- **Режим зрителя:** выбираешь 2 шара, оба управляются ИИ — для записи видео боёв в TikTok/Shorts (так приводим игроков на сайт).

## Реклама (AdSense H5 Games Ads)

Один модуль `ads.js` поверх Ad Placement API (`adBreak` / `adConfig`). До одобрения AdSense — тестовый режим `data-adbreak-test="on"`.

- С ID-заглушкой из нулей реклама работает только на localhost (Google отдаёт тестовые ролики); на настоящем домене — ничего, пока не вставлен реальный ID.
- **Ролики за награду** (`type: 'reward'`):
  - возродить шар с 50% HP — один раз за матч;
  - ×2 монеты после победы;
  - попробовать закрытый шар на один матч.
  Кнопка показывается только если API сообщил, что ролик доступен (`beforeReward`).
- **Между матчами** (`type: 'next'`): не в первые 3 матча; частоту дополнительно режет сам Google.
- **Баннеров нет.**
- **Халяль (без кода, в кабинете AdSense):** «Блокировка объявлений» → чувствительные категории: азартные игры/ставки, знакомства, алкоголь и т. п.; общие категории: кредиты/займы. Google не гарантирует 100% фильтрацию — проверять через «Центр проверки объявлений».
- **Согласие GDPR:** через «Конфиденциальность и сообщения» в AdSense, без кода.

- Статика на Vercel, свой домен (решим при запуске).

- Аккаунт AdSense — только 18+, оформляется на родителя.

## Структура

```

```

## Тесты

`node --test`, без зависимостей. Детерминированная симуляция с фиксированным сидом:
отражение от стен, урон при столкновении + перезарядка, каждая способность, конец раунда, переход шара-победителя в следующий раунд, конец матча, внезапная смерть.
