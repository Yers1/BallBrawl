# BallBrawl v2.1 — управление в бою: рывок + суперудар

Под-проект 1 из 4 (дальше: шары/скины/геймификация → графика → онлайн).
Проблема: игрок прицеливается один раз и дальше только смотрит. Цель: влиять на бой всё время.

## Рывок

- Тап/клик по арене во время боя → все живые шары твоей стороны делают рывок к точке.
- Буст: скорость ×2,2 на 0,35 с, самонаведение выключено, удар во время буста — урон ×1,5 (таран).
- Пиявка, прилипшая к врагу, при рывке отлипает.
- Заряды: 3, один восстанавливается за 2,5 с. Нет заряда — тап игнорируется.

## Суперудар

- Шкала 0–100 на сторону. Получил урон → +0,8×урон себе; нанёс → +1,2×урон. Внезапная смерть шкалу не копит. Новый раунд — шкала 0.
- Полная → кнопка СУПЕР (и пробел). Срабатывает у первого живого шара стороны, цель — ближайший враг.

| Шар | Супер |
|---|---|
| Обычный | Таран: буст ×3 на 0,6 с прямо во врага, удар ×2 |
| Пиявка | Прыжок: мгновенно прилипает к врагу на 3 с, высасывание ×2 |
| Клетка | Деление: сразу 2 мини-клетки, сама не умирает |
| Паук | Ловушка: паутина r 80 под врагом на 3 с, замедление ×0,25 |
| Ниндзя | Веер: 7 сюрикенов веером ±0,6 рад |
| Поезд | Экспресс: поезд через позицию врага, предупреждение 0,4 с, урон 30 |

## Команды и детерминизм

- `act(world, side, {type:'dash', x, y} | {type:'super'})` применяется между шагами, пишется в `world.log` с номером кадра `world.tick`.
- Тот же сид + тот же лог по тем же кадрам = тот же бой (тест). Это основа будущего онлайна: по сети идут только команды.

## ИИ

`createAI(side, level)` → `think(world, dt)`, вызывается каждый кадр. `skill = (level−1)/29`.
- Рывок: раз в `3 − 2,1·skill` с (± случайность) в упреждённую позицию врага с ошибкой `(1−skill)·60`.
- Уклонение от рельс вражеского поезда, если `skill > 0,3`.
- Супер: через `2 − 1,7·skill` с после заполнения.
- Режим зрителя и баланс-скрипт: ИИ с обеих сторон.

## Интерфейс

- Под ареной панель: слева 3 молнии (заряды, у следующей — прогресс), справа круглая кнопка СУПЕР с заливкой по кругу, светится когда готова.
- Эффекты: шлейф при бусте, кольцо в точке тапа, ударная волна + название супера при срабатывании.
- Обучение: в первых 2 матчах подсказки «Тапни по арене — рывок» и «Супер готов — жми!».
- Карточки шаров показывают и способность, и супер.

## Тесты

Рывок (заряд, направление, регенерация, ×1,5), шкала (копится, не от внезапной смерти, супер только при 100, сброс), каждый супер, повтор боя по логу, ИИ использует рывки и супер, баланс 35–65% с ИИ.
