# BallBrawl — битва шаров

Веб-игра: шары со суперсилами дерутся в арене. Собираешь отряд из 3 шаров, целишься и запускаешь. В бою тапаешь по арене, чтобы сделать рывок (3 заряда), а когда шкала заполнится, жмёшь СУПЕР: у каждого шара свой суперудар.
12 шаров: Обычный, Пиявка, Клетка, Паук, Ниндзя, Поезд, Магнит, Бомба, Черепаха, Молния, Ёж, Лёд. У каждого своя способность и супер.
**Путь кубков** на главном экране: за победы дают кубки, по пути открываются шары, скины и монеты (награда навсегда, даже если кубки упали). Есть скины (только внешний вид), 3 задания дня, награда за вход 7 дней подряд и достижения. Никаких случайных сундуков: каждая награда известна заранее.
**Вызов друга по ссылке:** отряд, сид, ник и уровень лежат прямо в ссылке, сервер не нужен. Друг играет тем же отрядом, после боя может отправить ответный вызов со своим результатом.
Ники только из готовых слов («Быстрый Ёж 482»), никакого свободного текста. Игра рассчитана на детей, поэтому реклама идёт в детском режиме (неперсонализированная). Работает без интернета (service worker).
Заработок на рекламе Google AdSense (H5 Games Ads), харам-категории блокируются в кабинете AdSense.

Чистый JavaScript и Canvas, без зависимостей и без сборки. Папка = готовый сайт.

## Запустить у себя

```bash
npm run dev
```

Открой http://localhost:5173. Нужен Python (`tools/dev.py` — обычный статический сервер, только запрещает браузеру кэшировать файлы). Просто открыть `index.html` двойным кликом не получится из-за ES-модулей.
На localhost Google показывает **тестовую** рекламу («Rewarded ad example»), так можно проверить все рекламные кнопки.

## Тесты и баланс

```bash
npm test
```

```bash
npm run balance
```

`balance` прогоняет тысячи боёв компьютера против компьютера, с рывками и суперами, и печатает таблицу побед: строка против столбца, в процентах.
Правило: средний процент побед каждого шара держим примерно в диапазоне **35–65%**. Сейчас все шары в пределах 43–56%, и есть контрпики (например, Пиявка против Обычного и Ниндзя против Пиявки).

## Как устроен код

| Файл | Что делает |
|---|---|
| `src/sim.js` | Физика одного раунда: движение, отскоки, самонаведение, урон при ударе, рывок, шкала супера, внезапная смерть. Детерминированная, без DOM. Команды игрока идут через `act()` и пишутся в `world.log`: «сид + лог» в точности повторяет бой, это основа будущего онлайна. |
| `src/balls.js` | Шары: HP, цвет, цена и способности. Все цифры баланса лежат вверху файла. |
| `src/match.js` | Отряды, раунды, ИИ-прицел, возрождение. |
| `src/progress.js` | Кубки, путь, скины, задания, ежедневная награда, достижения, перенос старых сохранений. Чистые функции, покрыты тестами. |
| `src/meta.js` | Главный экран: вкладки Путь, Шары (скины), Задания, Профиль. |
| `src/ai.js` | Компьютер в бою: рывки в упреждение, уклонение от поезда, супер. Сила растёт с уровнем. |
| `src/render.js` | Рисование: арена, шары, паутина, поезд, сюрикены, искры, цифры урона, тряска. |
| `src/main.js` | Экраны, прицел, игровой цикл, сохранение, реклама. |
| `src/ads.js` | Обёртка над AdSense Ad Placement API. |
| `src/i18n.js` | Тексты на русском и английском (язык берётся из браузера). |
| `src/nick.js` | Ники из проверенных списков слов; хранятся как номера слов. |
| `src/challenge.js` | Кодирование и строгая проверка ссылок-вызовов. |
| `src/sfx.js` | Звуки на Web Audio, без аудиофайлов. |
| `sw.js`, `manifest.webmanifest` | Офлайн-режим и установка на телефон. |
| `c/index.html` | Ссылки-вызовы ведут на `/c/`, чтобы их открытия считались отдельной страницей в аналитике. |

**Новый шар:**
1. Запись в `BALLS` в `src/balls.js`, вместе с `onSuper`.
2. Имя, описание, название и описание супера в `src/i18n.js`, на обоих языках.
3. По желанию — украшение в `deco()` в `src/render.js`.
4. Прогнать `npm test` и `npm run balance`.

## Запуск в интернет: чек-лист

1. **Домен.** Купи свой (примерно $10 в год, например Porkbun, Namecheap или прямо в Cloudflare). На бесплатный адрес `*.pages.dev` AdSense сайт не примет.
2. **Хостинг — Cloudflare Pages.** Бесплатный тариф Vercel запрещает сайты с рекламой, поэтому не Vercel. В Cloudflare: Workers & Pages → Create → Pages → загрузить папку (или подключить GitHub). Сборка не нужна, папка = сайт. Привяжи домен в Custom domains.
3. **Аналитика.** В настройках проекта Pages включи **Web Analytics** — без cookie, код не нужен. Ссылки-вызовы открываются через `/c/`, поэтому их видно отдельной страницей.
4. **Почта в политике.** Замени `CONTACT_EMAIL` в `privacy.html` на свою почту.
5. **Аккаунт AdSense.** Нужно 18+, поэтому оформляй на родителя. Добавь сайт и подтверди его: скрипт AdSense уже стоит в `index.html`.
6. **Подать заявку на H5 Games Ads** (реклама внутри игр): https://adsense.google.com/start/h5-games-ads/
7. **Вставить свой ID.** Замени `ca-pub-0000000000000000` на свой в двух местах: `index.html` и `ads.txt`. Пока стоит ID из нулей, на настоящем домене реклама не показывается вообще.
8. **После одобрения** убери `data-adbreak-test="on"` из `index.html`, иначе пойдёт только тестовая реклама.
9. **Халяльные настройки**, без кода, в кабинете AdSense:
   - «Защита бренда» → «Блокировка объявлений»;
   - **Чувствительные категории:** заблокируй азартные игры и ставки, знакомства, алкоголь и всё сомнительное из списка;
   - **Общие категории:** заблокируй кредиты и займы, то есть всё, где риба;
   - раз в неделю заглядывай в «Центр проверки объявлений» и блокируй то, что проскочило. Google не гарантирует 100% фильтрацию.
10. **Детский режим и GDPR:** в коде уже стоят `data-tag-for-child-directed-treatment="1"` и `data-tag-for-under-age-of-consent="1"`, поэтому вся реклама неперсонализированная. Окно согласия для Европы не должно предлагать персонализацию.

## Где взять игроков

Сайт сам никто не найдёт. Самый дешёвый путь — **режим зрителя**:
- выбираешь два шара, записываешь экран и выкладываешь в TikTok, YouTube Shorts или Reels с подписью «Кто победит — Пиявка или Поезд?»;
- ссылка на игру в профиле;
- такие видео «какой шар победит» хорошо набирают просмотры.
