# BallBrawl — битва шаров

Веб-игра: шары со суперсилами дерутся в арене. Собираешь отряд из 3 шаров, целишься, запускаешь, дальше бой идёт сам.
Шары: Обычный, Пиявка, Клетка, Паук, Ниндзя, Поезд. Лестница из 30 уровней, монеты, магазин, режим зрителя.
Заработок на рекламе Google AdSense (H5 Games Ads), харам-категории блокируются в кабинете AdSense.

Чистый JavaScript и Canvas, без зависимостей и без сборки. Папка = готовый сайт.

## Запустить у себя

```bash
npm run dev
```

Открой http://localhost:5173. Нужен Python; подойдёт любой статический сервер, просто открыть `index.html` двойным кликом не получится из-за ES-модулей.
На localhost Google показывает **тестовую** рекламу («Rewarded ad example»), так можно проверить все рекламные кнопки.

## Тесты и баланс

```bash
npm test
```

```bash
npm run balance
```

`balance` прогоняет тысячи боёв компьютера против компьютера и печатает таблицу побед: строка против столбца, в процентах.
Правило: средний процент побед каждого шара держим примерно в диапазоне **35–65%**. Сейчас все шары в пределах 39–54%.

## Как устроен код

| Файл | Что делает |
|---|---|
| `src/sim.js` | Физика одного раунда: движение, отскоки, самонаведение, урон при ударе, внезапная смерть. Детерминированная, без DOM. |
| `src/balls.js` | Шары: HP, цвет, цена и способности. Все цифры баланса лежат вверху файла. |
| `src/match.js` | Отряды, раунды, лестница, монеты, ИИ-прицел, возрождение. |
| `src/render.js` | Рисование: арена, шары, паутина, поезд, сюрикены, искры, цифры урона, тряска. |
| `src/main.js` | Экраны, прицел, игровой цикл, сохранение, реклама. |
| `src/ads.js` | Обёртка над AdSense Ad Placement API. |
| `src/i18n.js` | Тексты на русском и английском (язык берётся из браузера). |

**Новый шар:**
1. Запись в `BALLS` в `src/balls.js`.
2. Имя и описание в `src/i18n.js`, на обоих языках.
3. По желанию — украшение в `deco()` в `src/render.js`.
4. Прогнать `npm test` и `npm run balance`.

## Запуск в интернет: чек-лист

1. **Домен.** Купи свой (примерно $10 в год, например Porkbun или Namecheap). На бесплатный адрес `*.vercel.app` AdSense сайт не примет.
2. **Хостинг.** Статика, сборка не нужна. Vercel: выполни команду ниже в этой папке и привяжи домен в настройках проекта. Подойдут и Netlify, и Cloudflare Pages.
   ```bash
   npx vercel --prod
   ```
3. **Почта в политике.** Замени `CONTACT_EMAIL` в `privacy.html` на свою почту.
4. **Аккаунт AdSense.** Нужно 18+, поэтому оформляй на родителя. Добавь сайт и подтверди его: скрипт AdSense уже стоит в `index.html`.
5. **Подать заявку на H5 Games Ads** (реклама внутри игр): https://adsense.google.com/start/h5-games-ads/
6. **Вставить свой ID.** Замени `ca-pub-0000000000000000` на свой в двух местах: `index.html` и `ads.txt`. Пока стоит ID из нулей, на настоящем домене реклама не показывается вообще.
7. **После одобрения** убери `data-adbreak-test="on"` из `index.html`, иначе пойдёт только тестовая реклама.
8. **Халяльные настройки**, без кода, в кабинете AdSense:
   - «Защита бренда» → «Блокировка объявлений»;
   - **Чувствительные категории:** заблокируй азартные игры и ставки, знакомства, алкоголь и всё сомнительное из списка;
   - **Общие категории:** заблокируй кредиты и займы, то есть всё, где риба;
   - раз в неделю заглядывай в «Центр проверки объявлений» и блокируй то, что проскочило. Google не гарантирует 100% фильтрацию.
9. **Согласие GDPR:** «Конфиденциальность и сообщения» → сообщение для Европы. Без кода.

## Где взять игроков

Сайт сам никто не найдёт. Самый дешёвый путь — **режим зрителя**:
- выбираешь два шара, записываешь экран и выкладываешь в TikTok, YouTube Shorts или Reels с подписью «Кто победит — Пиявка или Поезд?»;
- ссылка на игру в профиле;
- такие видео «какой шар победит» хорошо набирают просмотры.
